# Sinew · company brain

The connective tissue of your company: one governed graph of how customers, orders,
deliveries, tickets, campaigns and decisions connect, built on FalkorDB. Agents answer
through named graph tools, and every answer shows its path and respects who is asking.

Built for the WeMakeDevs x FalkorDB Graph Hacks hackathon (Oct 2026). Work in progress.
